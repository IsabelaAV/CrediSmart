## Descripción del Proyecto

**CreditSmart** es una aplicación web interactiva diseñada para una entidad financiera digital (FinTech). La plataforma permite a los usuarios explorar diferentes líneas de crédito, simular préstamos calculando cuotas estimadas según tasas e intereses, y completar un formulario integral de solicitud en línea.

El proyecto está desarrollado utilizando **HTML5 semántico**, **Bootstrap 5.3** para el diseño *responsive* y maquetación basada en componentes, y estilos personalizados en **CSS3**.
